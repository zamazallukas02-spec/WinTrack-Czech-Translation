# WinTrack-Czech-Translation
Community Czech translation for WinTrack 17.0.
# WinTrack 17.0 – Český překlad

První komunitní český překlad programu WinTrack 17.0.

## Instalace

1. Stáhněte soubor `Wintrack_czech_Translate_Full.exe`
2. Zkopírujte jej do složky s WinTrackem
3. Spusťte program

## Informace

- Přeloženo do češtiny
- Přeložena menu, dialogová okna a systémové texty
- Verze: WinTrack 17.0
